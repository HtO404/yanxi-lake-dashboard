# 严西湖水质管理仪表盘：轮播图接入与 veFaaS 部署设计

## 项目背景

`e:\TraeCode\严西湖水质管理仪表盘` 下已存在单文件大屏仪表盘 `index.v4.0.html`，展示武汉市光谷第二十七小学作为严西湖市级民间河湖长的水质监测数据、巡查记录、媒体事迹等。当前轮播图模块已预留 DOM 与样式，但代码仍引用不存在的 `assets/photos/patrol_XX.jpg`，而真实照片位于 `轮播图/` 目录下。

## 目标

1. 将 `轮播图/` 下全部 53 张可用图片按文件名顺序嵌入轮播。
2. 通过火山引擎 veFaaS 创建新应用并绑定新网关，完成轻量化线上部署。
3. 输出可直接访问的公网链接。

## 设计决策

### 轮播图接入：方案 B（原文件名清单式）

- 在 HTML 中新增 `CAROUSEL_FILES` 数组，按 `轮播图/` 下实际文件名排序。
- 轮播 JS 从该数组读取 `src = '轮播图/' + fileName`。
- 保留原始文件名，不复制/重命名图片，避免冗余。
- 更新 `TOTAL` 为实际图片数量（53）。

### 部署：veFaaS 静态站点应用

- 使用 `@volcengine/vefaas-cli` 应用工作流。
- 应用类型选择静态站点（Static Site）。
- 上传目录为项目根目录，入口文件为 `index.v4.0.html` 或重命名后的 `index.html`。
- 绑定新网关，获取默认公网域名。
